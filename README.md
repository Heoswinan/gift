# 罐罐旅游指南

这是一个可在手机和电脑浏览器中使用的旅游地图。网页和 API 由同一个 Node.js 服务提供，地点、点评、点评回复和“有用”投票保存在 PostgreSQL 中。

## Render 公网部署

1. 将仓库中的所有文件提交并推送到 GitHub。
2. 注册 Render 账号并授权 Render 访问该 GitHub 仓库。
3. 在 Render 控制台选择 **New → Blueprint**，连接仓库并确认使用仓库根目录的 `render.yaml`。
4. Render 会创建网页/API 服务和 PostgreSQL 数据库。首次部署成功后，在服务页面复制 `onrender.com` 地址；该 HTTPS 地址可在手机、电脑等设备上打开。

应用启动时会自动创建所需的数据表，不需要手工执行 SQL。Render Blueprint 将网页和 API 放在同一域名下，不需要另配跨域规则或把密钥写进前端。

### 免费方案限制

当前 Blueprint 使用 Render 免费服务。Render 的免费 Web Service 空闲 15 分钟后会休眠，下一位访客打开时可能要等待约一分钟；免费 PostgreSQL 数据库在创建 30 天后到期，宽限期结束后数据会被删除，且免费数据库不提供备份。免费方案适合试运行，不适合承诺长期保存数据或持续快速响应。正式长期使用前，请在 Render 控制台升级服务和数据库，并按需设置备份。

## 访客写入说明

网页使用昵称登录，不需要注册、验证码或人工审核；昵称保存在当前设备浏览器中，点评和对点评的回复会使用该昵称并立即公开（勾选匿名点评时不展示点评昵称）。昵称登录不是账号身份验证，任何人都可以使用相同昵称。地点、点评和回复无需审核即可发布；服务端设有基础 IP 频率限制（每 IP 每小时最多 5 个地点、10 条点评、20 条回复；每分钟最多 60 次投票），但这只是轻量级防滥用措施。投票的访客标识保存在各自浏览器中，因此清除浏览器数据或更换设备后，投票身份会变化。

## 本地运行

需要 Node.js 20+ 和一个 PostgreSQL 数据库。设置 `DATABASE_URL` 后运行：

```powershell
$env:DATABASE_URL = "postgres://用户名:密码@主机:5432/数据库名"
npm install
npm start
```

然后访问 `http://localhost:3000/`。不要把数据库连接字符串提交到 GitHub。
